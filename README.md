# DNA AI 홈페이지 초안

정적 HTML/CSS/JavaScript로 만든 로컬 초안입니다. `index.html`을 열거나 정적 서버로 미리 볼 수 있습니다. 기존 `platform/` 분석 도구는 수정하지 않았습니다.

## 콘텐츠 기준

- 사업 영역과 네 가지 서비스는 2026-11-10 사용자 요청을 기준으로 작성했습니다.
- 검색광고, SNS, 퍼포먼스, 타게팅, DB 유입, 콘텐츠·홈페이지 제작 등 키워드는 [아이써치마케팅 공개 사이트](https://isearch-ad.com/)의 서비스 범주를 참고했습니다. 문장과 디자인을 복제하지 않았습니다.
- 자산 라이브러리 `03_Business/BRAND_COPY_DRAFT.md`는 문구 방향만 검토했습니다. 실적·효과·운영 상태는 검증되지 않아 사용하지 않았습니다.
- 연락처는 제공되지 않아 실제 문의 전송 기능을 연결하지 않았습니다. `contact@example.com`은 코드상 임시 값이며 클릭 시 메일을 보내지 않고 안내 문구를 표시합니다.
- 의존성: 없음. Google Fonts 접속이 안 되면 시스템 글꼴을 사용합니다.
- 검증 범위: JavaScript 구문 및 내부 앵커 연결 확인. 로컬 HTTP 서버는 시작했지만 이 환경에서 루프백 접속이 차단되어 브라우저 화면 검증은 완료하지 못했습니다. 서비스 연동과 배포는 포함하지 않습니다.
